# E-commerce Sales Data Analysis

## Project Overview
This project analyzes e-commerce order data to understand sales performance, product demand, customer purchasing patterns, discounts, payment methods, and profitability.

## Objectives
- Clean and validate e-commerce data.
- Analyze sales, net revenue, and profit.
- Identify top-performing products and categories.
- Compare sales across payment methods and locations.
- Explore monthly and weekday sales trends.
- Present business insights and recommendations.

## Dataset
- Initial dataset: 380 rows and 22 columns.
- Key fields: Order Date, Product, Category, Quantity, Unit Price, Discount, Payment Mode, Order Status, Net Amount, and Profit.
- Customer identifiers are excluded from the public dataset.

## Tools and Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook / Google Colab.

## Project Workflow
1. Data loading and understanding
2. Data quality checks and cleaning
3. Exploratory data analysis (EDA)
4. Sales and profitability analysis
5. Data visualization
6. Business insights and recommendations
